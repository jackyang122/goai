# Personal Learning OS — 产品设计计划

> 版本 v1。已确认的关键决策：①首页 = Dashboard；②简约风格；③默认 Persona = Teacher；④核心 = Learner State + 6 Skills + Mastery Engine，并补 Dashboard / Reader。工程执行见 [实施方案.md](实施方案.md)，接口见 [API协议.md](API协议.md)。

---

## 1. 产品定位

**一句话**：把 AI 从「问答工具」升级为「终身学习伙伴」——在同一 Agent 大脑上，辅导、解题、测验、研究、可视化、精通练习自由切换。

三大差异化（设计北极星）：
1. **统一 Agent 运行时**：切换的是目标，不是引擎，上下文随学习者流转。
2. **互联学习上下文**：知识库、书、草稿、笔记、题库、人格、记忆在每个工作流中始终可用。
3. **可审计的记忆**：三级记忆 + Memory Graph，每条结论可追溯到原始证据。

## 2. 目标用户

**全体学生**（不限年龄，K12 到高等/自学者）。设计上兼顾：低门槛（首启即用）、可成长（深度能力随需展开）、可信（证据可溯）。

## 3. 信息架构（一级 5 区）

| 一级导航 | 路由 | 子页 | 角色 |
|---|---|---|---|
| **仪表盘** | `/`（首屏） | — | 状态总览 + 今日推荐 + AI 入口 |
| **学习** | `/learn` | Book / Reader / Notebook / Flash Cards | 沉浸输入 |
| **练习** | `/practice` | Quiz / 错题本 | 输出检验 |
| **对话** | `/home` | — | 自由 Agent 对话（Teacher 默认） |
| **我的** | `/me` | Knowledge / Memory / Skills / Settings | 资产与配置 |

- Dashboard 与对话分立：仪表盘是「看状态 + 被推荐」，对话是「主动问」；顶栏「问 AI」互通。
- 简约导航：一级 5 项，避免过载；二级内容收进 Tab。

## 4. 核心概念

```
        Unified Learning Agent（单一 Agent）+ 6 Skills
                       │ 读/写
                Learner State（持久核心）
        ┌──────────┬──────────────┬──────────────┐
   Knowledge/RAG  Question Bank  Mastery Engine  Session Memory
```

**6 Skills**：`learning-plan` 学习规划 · `homework-coach` 作业辅导 · `error-diagnosis` 错因诊断 · `personal-explain` 个性化讲解 · `adaptive-practice` 自适应练习 · `mistake-summary` 错题归纳。

闭环：`error-diagnosis → mistake-summary → adaptive-practice → mastery↑ → learning-plan 调整`。

## 5. 页面设计要点

- **Dashboard**：问候 + 连续天数；4 KPI（今日时长 / 整体掌握+本周提升 / 本周题量 / 连续天数）；今日推荐（learning-plan）；Mastery Path 轨道；薄弱知识点；待复习闪卡；AI 洞察卡（带来源）。
- **对话**：Persona 切换（Teacher/Peer/Research，默认 Teacher）；消息气泡 + Skill 角标 + 引用脚注；快捷建议。
- **学习**：Book（AI 生成的区块化教材，沉浸衬线）/ Reader（PDF+AI 侧栏）/ Notebook / Flash Cards（可翻转）。
- **练习**：生成测验 → 作答 → 自动批改 → 错题入本，全闭环可视化。
- **我的**：多引擎知识库、三层记忆、6 技能、个性化设置。

## 6. 设计系统（简约）

- 中性 zinc 底 + **单一 indigo 强调色**（AI 时刻）；亮/暗双模。
- 掌握度语义色：红 <50% / 琥珀 50–75% / 绿 >75%。
- 字体：UI 无衬线（Inter），阅读态衬线（Source Serif）—— 区分「工具」与「沉浸」。
- 动效：统一的「思考中 / 引用中 / 生成中」三态（Framer Motion）。
- 响应式：桌面优先；平板支持阅读；手机精简 Dashboard + 对话 + 闪卡。

## 7. 学习流程

```
首页 Dashboard（被推荐） ──▶ 学习 Book/Reader（输入）
        │                          │
        │                          ▼
        │                     练习 Quiz（检验）─▶ 错题本
        │                                          │
        ▼                                          ▼
   对话 Teacher（答疑）◀── Memory 沉淀 ◀── Flash Cards（巩固）
```

## 8. 路线图（与实施方案一致）

- **P0 地基** ✅：工程、设计系统、契约层、Mock。
- **P1 Dashboard 闭环**：LearnerState 端点 + 3 核心 Skill，真实数据驱动。
- **P2 对话 + KB**：接 DeepTutor `/ws` + Knowledge Center。
- **P3 检验闭环**：Quiz 全链路 + MasteryEngine + Memory Graph。
- **P4 深化**：多引擎 KB、Deep Question、Partners。
