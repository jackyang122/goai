# 对话模块使用亮点

> 对话模块是 Personal Learning OS 的智能交互核心，以专业讲师风格贯穿学、练、测、评全流程。

---

## 亮点一：六大 Skill 一键切换，场景全覆盖

在同一个对话窗口中，无需切换页面即可完成所有学习任务。AI 自动识别用户意图并路由到对应 Skill。

| 用户说 | 命中 Skill | 效果 |
|--------|-----------|------|
| "帮我规划今天的复习" | learning-plan | 生成今日学习轨道 |
| "这道题我不会" | homework-coach | 分步引导解题 |
| "为什么做错了" | error-diagnosis | 诊断错因，更新薄弱点 |
| "解释一下顶点公式" | personal-explain | 直观 + 严格双视角讲解 |
| "出一道练习题" | adaptive-practice | 内嵌题目，直接作答批改 |
| "总结这周错题" | mistake-summary | 聚合错误模式，给出趋势 |

### 案例：一次完整的学习闭环

```
用户：帮我规划今天的复习
  → 讲师读取掌握度，生成任务卡片
  → 用户点击"开始第 1 项"

用户：解释一下顶点公式
  → 讲师双视角讲解（直观 + 严格）
  → 附带 KaTeX 公式渲染
  → 追问"要出题检验吗？"

用户：出一道练习题
  → 内嵌选择题，用户直接点击作答
  → 批改后自动诊断错因
  → 更新薄弱点，安排下一题

用户：总结这周错题
  → 聚合错误模式，展示趋势
  → 建议优先补短板
```

## 亮点二：专业讲师风格，连贯一致

单一讲师角色，避免多角色切换带来的认知负担。讲师风格特点：

- **严谨**：引用知识库原文，所有回答附带来源
- **循循善诱**：辅导时分步引导，不直接给答案
- **自适应**：根据掌握度调整讲解深度和题目难度
- **可追溯**：每条引用可点击跳转到原文位置

### 案例：辅导 vs 直接给答案

```
用户：这道二次函数题怎么做？

讲师（分步引导）：
1. 先确认这是什么类型的问题（求顶点坐标）
2. 把已知量列出来：y = x² - 4x + 3
3. 想想哪个公式相关——顶点公式 (-b/2a, ...)
4. 代入计算试试

用户：我算出来是 (2, -1)
讲师：正确！关键是把 -b/2a 的负号记住——这是最常见的错误点。
```

## 亮点三：知识库引用，每句话有据可查

所有回答自动关联知识库原文，支持点击追溯。

### 案例：引用溯源

```
用户：什么是判别式？

讲师：判别式 Δ = b² - 4ac — 用于判断一元二次方程根的情况：
  • Δ > 0 → 两个不同实根
  • Δ = 0 → 一个重根
  • Δ < 0 → 无实根（两个共轭复根）

📎 数学核心知识库 · 二次函数.pdf p.4
  "判别式 Δ = b² - 4ac 决定根的性质"

📎 数学核心知识库 · 二次函数.pdf p.5
  "Δ > 0 时抛物线与 x 轴有两个交点"
```

## 亮点四：内嵌题目交互，对话即练习

题目直接在对话流中渲染，无需跳转到练习页面。

### 案例：选择题交互

```
讲师：抛物线 y = x² - 4x + 3 的顶点坐标是？

  ○ (2, 1)
  ● (2, -1)   ← 用户点击
  ○ (-2, -1)
  ○ (4, 3)

✅ 正确！配方 y = (x-2)² - 1，顶点 (2, -1)
  掌握度更新：二次函数 0.42 → 0.55
```

## 亮点五：自适应难度，因材施教

题目难度、讲解深度、辅导节奏都根据用户当前掌握度自动调整。

### 案例：难度自适应

```
场景 A（掌握度 0.42）：
讲师：抛物线 y = x² - 4x + 3 的顶点坐标是？
      选项清晰，直接套用公式即可

场景 B（掌握度 0.78）：
讲师：抛物线 y = 2x² + 8x + 5 的顶点坐标是？
      需要配方计算，难度提升
```

## 亮点六：全场景上下文贯通

同一个对话线程中，AI 能引用之前的上下文，实现跨 Skill 的连贯对话。

### 案例：上下文贯通

```
第一轮（讲解）：
用户：解释一下顶点公式
讲师：配方 y = a(x + b/2a)² + (4ac-b²)/4a...

第二轮（出题，引用刚才的讲解）：
用户：出题检验一下
讲师：好，刚才讲了顶点公式，来试一题：
      y = x² - 6x + 5 的顶点是？

第三轮（诊断，关联上一步）：
用户：我选了 (3, -4)，但答案是 (3, -4)，我答对了
讲师：正确！你的掌握度已提升到 0.65
      要继续下一题还是换一个话题？
```

## 亮点七：多场景入口联动

对话模块与其他模块深度联动：

| 入口 | 跳转到对话 | 场景 |
|------|-----------|------|
| Dashboard 薄弱点 | 点击薄弱点 → 自动发起讲解 | error-diagnosis / personal-explain |
| 学习页面 | 选中知识 → 侧栏打开对话 | personal-explain |
| 错题本 | 点击错题 → 诊断错因 | error-diagnosis |
| 学习计划 | 点击任务项 → 关联对话 | learning-plan |
