# Personal Learning OS — 模块方案（未来实现）

> Demo 已实现各模块的可交互界面与 Mock 数据（见 [实施方案 §2](实施方案.md)）。本文给出每个模块**接入真实后端**的目标方案、端点与开源组件选型，供后续按 [API协议](API协议.md) 逐个落地。优先级 P1→P4。

---

## 1. Dashboard（仪表盘）— P1

- **Demo 现状**：全部组件已实现，数据来自 Mock `getLearnerState()`。
- **目标**：由真实 LearnerState + MasteryEngine 驱动；AI 洞察来自 `mistake-summary`。
- **端点**：`GET /api/learners/{id}/state`；`POST /api/skills/invoke`（`learning-plan` / `mistake-summary`）。
- **未来工作**：实时刷新（SWR/WebSocket 推送 mastery 变化）；Mastery Path 节点点击进入对应 Book/Quiz。
- **组件**：复用现有 `components/ui`；可加 recharts 做趋势图。

## 2. 对话 / Home（Teacher）— P2

- **Demo 现状**：Mock `sendMessage()` 关键词路由到 Skill，含引用。
- **目标**：接 DeepTutor `/ws/chat` 流式；Persona 影响系统提示；RAG 绑定 KB。
- **端点**：`WS /ws/chat`；`GET/POST /api/threads*`。
- **组件**：**assistant-ui**（`useExternalStoreRuntime`）+ KaTeX/Mermaid 渲染。
- **未来工作**：附件上传、子智能体调用（`consult_subagent`）、Partners 历史 import。

## 3. 学习 / Learn — P2/P3

### 3.1 Book（智能教材）
- **Demo 现状**：静态区块（文/公式/随堂测）展示「living book」概念。
- **目标**：从 KB/笔记本编译为类型化区块（text/quiz/animation/interactive）。
- **端点**：复用 DeepTutor Book capability；`POST /api/skills/invoke`（`personal-explain`）。
- **组件**：Markdown 渲染 + KaTeX + Mermaid + Chart.js。
- **未来工作**：区块级 AI 重写、协作编辑（Co-Writer 拆屏）。

### 3.2 Reader（阅读）
- **Demo 现状**：Mock 文档 + AI 侧栏。
- **目标**：**react-pdf** 真实预览 PDF/PPT；选中文本 → AI 讲解（带原文引用）。
- **端点**：`GET /api/kbs/{id}/documents/{doc}`；`POST /api/skills/invoke`（`personal-explain`）。
- **组件**：**react-pdf**；解析引擎 Docling/MinerU/PyMuPDF4LLM。

### 3.3 Notebook（笔记本）
- **Demo 现状**：静态笔记卡 + 新建占位。
- **目标**：从对话/Reader 一键保存；双向链接（类 Obsidian）。
- **端点**：`POST/GET /api/notes`（新增）。
- **组件**：Markdown 编辑器（如 Tiptap）。

### 3.4 Flash Cards（闪卡）
- **Demo 现状**：可翻转卡片，数据来自 `dueCards`。
- **目标**：间隔重复算法（FSRS）驱动 `due`；自动从错题/教材生成。
- **端点**：`GET /api/learners/{id}/cards?due=true`；`POST /api/cards/{id}/review`。
- **组件**：FSRS 实现（py-fsrs）。

## 4. 练习 / Practice — P3

- **Demo 现状**：`generateQuiz` → 作答 → `gradeAnswer` → 错题入本，全闭环（本地）。
- **目标**：题目由 LLM（`deep_question`）按薄弱点生成；批改由 Agent 评判；错题经 `error-diagnosis` 诊断。
- **端点**：`POST /api/quiz/generate`；`POST /api/quiz/grade`；`GET /api/learners/{id}/errors`。
- **组件**：DeepTutor Quiz capability + tool-ui（代码/公式执行）。
- **未来工作**：Deep Question 探究题、多题型、限时模式。

## 5. 知识库 / Knowledge — P2/P4

- **Demo 现状**：列表展示多引擎 KB（engine/status/文档数）。
- **目标**：创建/上传/检索全链路；可插拔引擎与解析器。
- **端点**：`POST /api/kbs`；`POST /api/kbs/{id}/documents`；`POST /api/kbs/{id}/search`。
- **组件**：**LlamaIndex** / **PageIndex** / **GraphRAG** / **LightRAG** / Obsidian vault；pgvector。
- **未来工作**：版本化索引、跨库检索、Obsidian 双向读写。

## 6. 记忆 / Memory + Memory Graph — P3

- **Demo 现状**：L1/L2/L3 三列展示。
- **目标**：三层记忆可审计、可编辑；Memory Graph 可视化，追溯每条结论到原始证据。
- **端点**：`GET /api/learners/{id}/memory`；`POST /api/memory`；`GET /api/learners/{id}/memory/graph`。
- **组件**：DeepTutor Memory（L1 traces / L2 facts / L3 synthesis）+ 图可视化（react-flow / Cytoscape）。

## 7. Mastery Engine — P3（横切）

- **目标**：`mastery` / `weakPoints` 的唯一权威写入方；综合答题、闪卡、诊断给出掌握度与趋势。
- **端点**：内部服务，消费 Skill 的 `sideEffects`；暴露 `GET .../state` 的 mastery 部分。
- **算法**：贝叶斯知识追踪（BKT）或 FSRS 衍生；按 topic 维护 level/trend/errorCount。

## 8. Skills 运行时 — P1/P3

- **目标**：单 Agent 循环按 `skill` 装配 tool/prompt；`POST /api/skills/invoke` 统一入口。
- **组件**：**DeepTutor + ADK**；capability pipeline 复用 chat/deep_solve/deep_question。
- **6 Skills 契约**：见 [API协议 §7](API协议.md)。

## 9. Partners / 子智能体 — P4

- **目标**：在对话轮次调用实时编程 CLI（Claude Code / Codex）或 Partner，导入历史对话，跑持久化 IM 伴侣。
- **端点**：DeepTutor Partners（15+ 渠道）；`POST /api/threads/{id}/consult`。
- **组件**：DeepTutor Partners + MCP Server。

---

## 实现顺序建议

P1：Dashboard 真实数据（LearnerState + `learning-plan`/`personal-explain`/`adaptive-practice`）→ P2：对话 `/ws` + KB → P3：Quiz 全链路 + MasteryEngine + Memory Graph → P4：多引擎 KB + Partners。每阶段验收见 [实施方案 §5](实施方案.md)。
