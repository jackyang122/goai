## 2. 场景一：答疑 (Q&A)

### 描述

用户直接提问，AI 以专业讲师风格回答。最基础的场景，也是使用频率最高的入口。

### 用户意图示例

```
"二次函数顶点怎么求？"
"什么是牛顿第二定律？"
"现在完成时和过去时的区别？"
```

### 对话流程

```
用户输入 ──▶ 路由到 chat / personal-explain skill
                │
                ├─▶ 检索 KB（如有相关文档）
                ├─▶ 读取 Memory（是否有历史记录）
                ├─▶ 生成回复（流式输出）
                └─▶ 附带引用来源（Citations）
```

### 交互要求

- 流式响应（打字机效果）
- KaTeX 公式渲染（数学/物理公式）
- 引用来源可点击追溯
- 支持多轮上下文

## 3. 场景二：学习规划 (Planning)

### 描述

AI 根据用户的掌握度数据、薄弱点和可用时间，自动生成每日/每周学习计划，包含具体任务项和预估时间。

### 用户意图示例

```
"帮我规划今天的复习"
"这周我每天有 30 分钟，怎么安排？"
"考前冲刺计划"
```

### 对话流程

```
用户输入 ──▶ learning-plan skill
                │
                ├─▶ 读取 LearnerState.mastery（各主题掌握度）
                ├─▶ 读取 LearnerState.weakPoints（薄弱点）
                ├─▶ 读取 LearnerState.preferences（偏好设置）
                ├─▶ 生成 PlanTask[]（任务列表 + 排序）
                └─▶ 写入 LearnerState.goals
```

### 交互要求

- 对话中展示**任务卡片**，每项含标题、预估时间、类型标签
- 卡片可勾选完成状态
- 点击任务可跳转到对应页面（学习/练习）
- 计划变更时自动更新 Dashboard

### 消息结构

```json
{
  "skill": "learning-plan",
  "content": "根据你当前的掌握度，我建议今天的安排是：",
  "tasks": [
    { "id": "t1", "title": "二次函数 · 精通路径", "estMinutes": 20, "type": "learn" },
    { "id": "t2", "title": "错题重练 · 3 道", "estMinutes": 15, "type": "practice" },
    { "id": "t3", "title": "英语阅读 · 1 篇", "estMinutes": 20, "type": "review" }
  ],
  "citations": [{ "source": "LearnerState · mastery[]", "snippet": "二次函数 0.42" }]
}
```

## 4. 场景三：作业辅导 (Coaching)

### 描述

用户遇到不会做的题目，AI 不直接给答案，而是通过苏格拉底式分步引导，帮用户自己找到解题思路。

### 用户意图示例

```
"这道题我不会"
"第二步怎么走？"
"我算出来是 3，但答案是 5，哪里错了？"
```

### 对话流程

```
用户输入 ──▶ homework-coach skill
                │
                ├─▶ 读取 Mastery（当前掌握度，调整引导深度）
                ├─▶ 分步输出 StepTrace[]
                │      step 1: 确认题目类型
                │      step 2: 列出已知量
                │      step 3: 选择相关公式
                │      step 4: 代入计算
                └─▶ 写入 recentActivity
```

### 交互要求

- 分步步骤以**可展开/收起的折叠面板**展示
- 每步可单独追问（"展开讲这一步"）
- 用户完成一步后自动推进下一步
- 支持在对话中**上传作业图片/PDF**

### 消息结构

```json
{
  "skill": "homework-coach",
  "content": "我们分步来，先不急着想答案：",
  "steps": [
    { "step": "先确认这是什么类型的问题", "detail": "函数？几何？" },
    { "step": "把已知量列出来", "detail": "" },
    { "step": "想想哪个公式和这些量相关", "detail": "" }
  ]
}
```

## 4. 场景四：自适应出题 (Quiz)

### 描述

AI 针对某个知识点讲解或错题讲解，自动生成配套练习题，支持在对话中直接作答和批改，形成"讲解/诊断 → 出题 → 作答 → 批改"闭环。

### 用户意图示例

```
"出一道二次函数的题"
"再难一点"
"我做完了，答案是 (2, -1)"
```

### 对话流程

```
用户输入 ──▶ adaptive-practice skill
                │
                ├─▶ 读取 weakPoints（薄弱点，确定出题方向）
                ├─▶ 读取 mastery（掌握度，确定难度）
                ├─▶ 生成 Question[]（选择题/填空题/开放题）
                ├─▶ 用户作答 → gradeAnswer 批改
                ├─▶ 写入 mastery（根据对错更新掌握度）
                └─▶ 写入 errorBook（如答错）
```

### 交互要求

- 对话中**内嵌题目交互组件**：
  - 选择题：选项按钮，点击后高亮/反馈对错
  - 填空题：输入框 + 提交按钮
  - 开放题：文本输入 + 人工评判
- 答完一题后自动出下一题（自适应调整难度）
- 批改结果附带解析

### 消息结构

```json
{
  "skill": "adaptive-practice",
  "content": "先来第 1 题：",
  "question": {
    "type": "choice",
    "prompt": "抛物线 y = x² - 4x + 3 的顶点坐标是？",
    "options": ["(2, -1)", "(2, 1)", "(-2, -1)", "(4, 3)"],
    "answer": "(2, -1)",
    "explanation": "配方 y = (x-2)² - 1，顶点 (2, -1)"
  }
}
```

## 5. 场景五：错题归纳 (Summary)

### 描述

AI 按时间范围（周/月/全部）聚合错题数据，输出错误类型分布、趋势和针对性建议。

### 用户意图示例

```
"总结我这周错题的规律"
"我最近主要在哪些地方犯错？"
"这周比上周有进步吗？"
```

### 对话流程

```
用户输入 ──▶ mistake-summary skill
                │
                ├─▶ 读取 ErrorBook（错题数据）
                ├─▶ 读取 weakPoints（薄弱点）
                ├─▶ 聚合分析：错误类型 × 频率 × 趋势
                ├─▶ 写入 weakPoints（更新薄弱点）
                └─▶ 写入 mastery（调整掌握度）
```

### 交互要求

- 展示**统计图表/聚合视图**：
  - 错误类型分布（柱状图/饼图）
  - 趋势（周 vs 周对比）
  - 高频错误知识点 Top N
- 每类错误可点击展开详情

### 消息结构

```json
{
  "skill": "mistake-summary",
  "content": "本周错题归纳：",
  "patterns": [
    { "type": "符号/正负号错误", "count": 5, "trend": "stable" },
    { "type": "概念混淆", "count": 2, "trend": "improving" }
  ],
  "suggestion": "建议优先补「符号与正负号」类，预计 2 天可显著改善。"
}
```

## 6. 当前能力与差距

### 当前实现 (`/home`)

| 功能 | 状态 | 说明 |
|------|------|------|
| 纯文本对话 | ✅ | 消息气泡 + 引用块 |
| 静态建议词 | ✅ | 4 条预设 |
| 流式响应 | ❌ | 无打字机效果 |
| KaTeX 公式渲染 | ❌ | 公式只能纯文本描述 |
| 附件上传 | ❌ | Paperclip 按钮为空 |
| 任务卡片 | ❌ | 规划结果只能文本展示 |
| 分步步骤 | ❌ | 辅导步骤只能文本展示 |
| 内嵌题目 | ❌ | 出题只能文本展示 |
| 统计图表 | ❌ | 归纳结果只能文本展示 |
| 工具执行 | ❌ | 代码/公式执行结果展示 |

### 差距分析

当前对话模块本质上是一个**通用聊天框**，所有 Skill 的输出都以纯文本形式展示。要真正支持 5 大场景，需要在消息渲染层增加**富内容组件**：

- **流式文本** → 基础体验，所有场景都需要
- **公式块** → 答疑、出题、辅导
- **任务卡片** → 规划
- **步骤面板** → 辅导
- **题目组件** → 出题
- **统计摘要** → 归纳
- **附件预览** → 答疑（知识库引用内嵌于答疑）

## 7. 实现优先级

### P1 — 基础体验

| 功能 | 依赖 | 场景 |
|------|------|------|
| 流式响应 | 后端 WebSocket | 所有场景 |
| KaTeX 公式渲染 | `katex` npm 包 | 答疑、讲解、出题、辅导 |
| 附件上传 | 后端文件上传接口 | 知识库引用、作业辅导 |

### P2 — 场景深化

| 功能 | 依赖 | 场景 |
|------|------|------|
| 内嵌题目交互 | 前端选择题/填空题组件 | 出题 |
| 任务卡片 | 前端任务列表组件 | 规划 |
| 分步步骤面板 | 前端折叠面板组件 | 辅导 |

### P3 — 高级能力

| 功能 | 依赖 | 场景 |
|------|------|------|
| 统计图表 | 前端图表库（recharts） | 归纳 |
| 工具执行展示 | 后端 tool-ui 执行环境 | 代码/公式执行 |
| 多模态输入 | 图片/语音输入 | 全场景 |
